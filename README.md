الجدول الدوري ثلاثي الأبعاد

جدول دوري تفاعلي ثلاثي الأبعاد في ملف HTML واحد، بدون مكتبات وبدون أي إعداد.

## المميزات
- 4 أشكال للعرض: جدول، كرة، حلزون، وشبكة، مع حركة انتقال سلسة
- اضغط على أي عنصر لتظهر بطاقة مكبّرة فيها أمثلة من الحياة الواقعية
- يدعم العربية والإنجليزية: أسماء العناصر والأمثلة
- زوم بالقرص بإصبعين أو بعجلة الماوس أو بالأزرار، مع تحريك الصفحة
- يشتغل على الجوال والكمبيوتر
