# الجدول الدوري ثلاثي الأبعاد

جدول دوري تفاعلي ثلاثي الأبعاد، بدون مكتبات وبدون أي إعداد.

## المميزات
- 4 أشكال للعرض: جدول، كرة، حلزون، وشبكة، مع حركة انتقال سلسة
- اضغط على أي عنصر لتظهر بطاقة مكبّرة فيها أمثلة من الحياة الواقعية
- سهم "التفاصيل العلمية": التوزيع الإلكتروني، نموذج بور المتحرك، المجموعة والدورة، الكتلة، الانصهار والغليان، الكثافة، السالبية الكهربية، وسنة الاكتشاف
- يدعم العربية والإنجليزية: أسماء العناصر والأمثلة والتفاصيل
- زوم بالقرص بإصبعين أو بعجلة الماوس أو بالأزرار، مع تحريك الصفحة
- قائمة جانبية للتخصيص الكامل: 7 طرق للتلوين (تصنيف، فئة s/p/d/f، حالة المادة، السالبية، الكتلة...)، ألوان قابلة للتعديل، 4 أشكال للبطاقات، حجم وتوهج وتعبئة، خطوط، قوالب جاهزة (منها ثيم فاتح للبروجكتر)، ويحفظ إعداداتك
- إمكانية وصول: كل العناصر قابلة للفتح بلوحة المفاتيح (Tab ثم Enter/Space، والأسهم للتنقل، وEsc للإغلاق)، والقوائم المغلقة غير قابلة للتركيز
- أداء: حلقة الرسم تتوقف تلقائياً عندما لا توجد حركة
- يشتغل على الجوال والكمبيوتر

## بنية المشروع
- `index.html`: الصفحة
- `style.css`: التصميم
- `app.js`: المشهد ثلاثي الأبعاد والتفاعل
- `panel.js`: لوحة التفاصيل (التوزيع الإلكتروني ونموذج بور)
- `settings.js`: التخصيص (ألوان، أشكال، خطوط، قوالب) والقائمة الجانبية
- `data/elements.js`: الرموز والأسماء (عربي/إنجليزي)
- `data/examples.js`: أمثلة الحياة الواقعية
- `data/details.js`: البيانات العلمية (قيم تقريبية، راجعها قبل الاعتماد عليها)

## التشغيل
افتح `index.html` بأي متصفح.
